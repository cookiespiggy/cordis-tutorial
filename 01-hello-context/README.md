# 第 01 课：Context 与第一个插件

## 本課目标

建立对 Cordis 最基础的认知：

- `new Context()` 创建根上下文，它是整个应用的入口。
- 插件（plugin）是一个函数 `(ctx, config) => void`。
- `ctx.plugin()` 注册插件，`ctx.on()` / `ctx.emit()` 进行事件通信。

## 关键概念

| 概念 | 说明 |
| --- | --- |
| `Context` | 所有能力的载体；插件、服务、事件都挂在上下文上。 |
| `plugin` | 一个 `(ctx, config) => any` 的函数，被 `ctx.plugin()` 注册。 |
| `fiber` | 插件的「生命周期单元」。插件在被激活（ACTIVE）后其逻辑才会执行。 |
| `emit` / `on` | 事件总线：发布 / 订阅。 |

## 运行

```bash
npm install
npm start
```

预期输出：

```
你好，世界！
```

## 常见误区

- **插件是异步激活的**：`ctx.plugin()` 之后不能立刻 `emit`，要用 `await` 等它就绪，否则监听器还没注册。
- **`ctx` 是子上下文**：插件函数收到的 `ctx` 只属于该插件，它的副作用/监听器会随插件卸载而自动清理。
